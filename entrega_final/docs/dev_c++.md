# Abrindo no Dev-C++

1. Extraia o ZIP inteiro, sem alterar a estrutura das pastas.
2. Abra `LanHouse.dev` no Dev-C++.
3. Acesse **Executar > Compilar e Executar** ou pressione F11.
4. O executavel sera criado como `lanhouse.exe`.
5. Execute o programa com a pasta do projeto como diretorio atual para que `data` seja localizado.

Alternativa: abra o terminal na pasta e execute `compilar.bat`.
O projeto esta configurado como C99 e utiliza apenas a biblioteca padrao de C.
