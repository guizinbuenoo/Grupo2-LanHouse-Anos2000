# Git e GitHub

O diretorio entregue ja contem um repositorio Git com commits separados. Para publicar:

```bash
git remote add origin URL_DO_REPOSITORIO
 git branch -M main
 git push -u origin main
```

Antes da apresentacao, confirme com `git log --oneline --all`. Cada integrante deve realizar e explicar seus proprios commits no repositorio remoto; trocar apenas o autor de um commit pronto nao comprova participacao.
