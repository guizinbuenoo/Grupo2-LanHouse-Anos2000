# Entrega Final - Lan House Byte 2000

Versao final comentada e pronta para demonstracao no MS Teams. Inclui projeto Dev-C++, codigo C99, testes, documentacao, relatorio, ordenacao, persistencia, comprovante, CSV e auditoria.

## Executar no Dev-C++

Abra `LanHouse.dev` e pressione F11. Nao mova o executavel para fora desta pasta, pois o sistema utiliza o diretorio `data`.

## Validar

- Windows/Dev-C++: execute `testar.bat` para os testes unitarios.
- GCC: execute `make test` para testes unitarios e de integracao.
- Consulte `VERIFICACAO.md` para o registro da validacao realizada antes da entrega.
- Consulte `docs/roteiro_apresentacao.md` para dividir a explicacao entre os integrantes.
