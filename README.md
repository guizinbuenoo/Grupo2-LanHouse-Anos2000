# GRUPO 2 - Lan House / Cyber Cafe Anos 2000

Projeto academico em linguagem C sobre controle de baias, sessoes e consumo em uma lan house dos anos 2000.

## Pacotes

- `checkpoint_1`: arquitetura inicial, `struct`, menu base e orientacao para repositorio GitHub.
- `checkpoint_2`: modulos funcionais de cadastro/abertura de sessao, consumo e listagens em funcoes separadas.
- `checkpoint_3`: sistema completo com relatorios, ordenacao, persistencia e auditoria.
- `entrega_final`: versao comentada, testada e preparada para Dev-C++ e apresentacao no MS Teams.

Cada pasta possui um projeto `.dev`, scripts de compilacao, testes e documentacao propria. Os fontes usam C99 e apenas a biblioteca padrao de C, aumentando a compatibilidade com o compilador MinGW do Dev-C++.
