# Checkpoint 3 - Sistema completo

Atende ao Checkpoint 3: sistema completo com relatorio financeiro, listagem ordenada por nome/preco, persistencia, historico CSV e auditoria operacional.

## Dev-C++

Abra `LanHouse.dev` e pressione F11. Tambem e possivel usar `compilar.bat`.

## Testes

No GCC: `make test`. Os testes verificam regras, calculos, estoque, persistencia, comprovante, CSV e fluxo completo.
