# Manual do usuario

1. Inicie o programa e escolha `Mapa de baias` para localizar uma baia livre.
2. Use `Abrir sessao`, informe a baia e o nome do cliente.
3. Durante o atendimento, use `Adicionar consumo` para associar produtos a baia.
4. Ao terminar, use `Fechar conta` e informe os minutos efetivamente utilizados.
5. O sistema mostra tempo, produtos e total, libera a baia e cria um comprovante em `data`.
6. Consulte `Relatorio financeiro` para ver o acumulado.

Os dados sao salvos apos cada operacao importante e novamente ao sair.
