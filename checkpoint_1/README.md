# Checkpoint 1 - Prototipo

Objetivo: demonstrar fundamentos de C com menu, vetores, funcoes, repeticao, decisao e validacao de entrada.

Funcionalidades: listar oito baias, ocupar uma baia, registrar valor de consumo e liberar a baia.

Use `make` para compilar e `make test` para executar o teste automatizado.

## GitHub

Na pasta raiz do projeto, execute `git init`, adicione os arquivos e crie o primeiro commit. Depois crie um repositorio vazio no GitHub, configure o `origin` e envie a branch `main`. A entrega completa inclui instrucoes detalhadas para essa publicacao.

## Dev-C++

Abra `LanHouse_CP1.dev` e pressione F11 para compilar e executar.
